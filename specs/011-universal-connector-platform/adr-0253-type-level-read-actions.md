# ADR-0253：接入类型级只读业务动作

## 决策

- 新业务动作唯一归属 `UcpConnectorPackage`，不得以 `system_id` 创建；`STANDARD_SAAS` 与 `CONTROLLED_API` 无例外，`INSTANCE_RESOURCE` 不创建独立动作。
- 动作只允许 `GET` 或查询型 `POST`，Host、认证、技术 Header、域名白名单均由接入类型及已发布模板继承。
- 发布动作及其 API 模板版本不可原地编辑；更新必须创建草稿版本并经测试、审批、发布后显式切换。
- Pipeline 固定引用已发布动作/模板版本；历史系统专属动作标记为 legacy，只读兼容既有运行，不自动提升或替换。
- 输出字段使用稳定 `field_id`；样本只持久化明确定义且非敏感字段，Schema 变化立即使当前样本失效。

## 替代范围

本 ADR 取代 X0235 中“系统实例内新建扩展业务能力”的新建、编辑、发布和停用路径；系统实例仅能启用、测试已发布的类型级动作。
