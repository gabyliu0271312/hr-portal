# 原子任务拆解

## A. 基线与数据模型
- [ ] X1801 固化质量状态/规则契约
  - 前置任务：无。
  - 功能范围：状态、严重级别、期间、批次、脱敏样例、错误码。
  - 代码交付物：schema、共享类型、API契约测试。
  - UI要求：不涉及UI。
  - 外部系统：保留质量事件扩展点。
  - 测试要求：schema、错误码、旧规则兼容。
  - 验收标准：非法配置拒绝，旧数据可读。
  - 完成定义：开发、测试、评审证据齐全。
- [ ] X1802 实现按期间质量状态模型
  - 前置任务：X1801。
  - 功能范围：表/关系/数据集/报表状态，运行批次和唯一键。
  - 代码交付物：ORM、migration、索引、upsert service、回滚方案。
  - UI要求：不涉及UI。
  - 外部系统：不涉及。
  - 测试要求：升级/回滚、并发upsert、旧历史。
  - 验收标准：同资产同期间一条当前状态，Alembic单head。
  - 完成定义：迁移演练及测试完成。

## B. 调度与同步触发
- [ ] X1810 抽取共享质量运行服务
  - 前置任务：X1801、X1802。
  - 功能范围：统一手动、定时、同步后，负责运行记录、状态和事件。
  - 代码交付物：`run_quality_rule` service、事务边界、审计。
  - UI要求：不涉及UI。
  - 外部系统：只发质量事件，不直发通知。
  - 测试要求：三入口一致、失败回滚、幂等重试。
  - 验收标准：所有入口产生一致记录和状态。
  - 完成定义：服务和调用方测试通过。
- [ ] X1811 修复质量定时handler
  - 前置任务：X1810。
  - 功能范围：校验payload，传递rule/period/batch/trigger上下文，返回检查行数。
  - 代码交付物：`scheduler/handlers.py`、调度单测。
  - UI要求：复用既有定时弹窗。
  - 外部系统：不直发飞书。
  - 测试要求：缺参数、规则不存在、失败、成功写job_runs。
  - 验收标准：不再调用错误签名，结果与手动一致。
  - 完成定义：日志、job_runs、quality_runs一致。
- [ ] X1812 接入同步成功后的异步触发
  - 前置任务：X1810、X1811。
  - 功能范围：同步成功后按`table+period+batch`查依赖并投递关系检查。
  - 代码交付物：事件消费者、批次/期间解析、重试。
  - UI要求：显示pending和来源。
  - 外部系统：复用现有事件/队列。
  - 测试要求：成功/失败、提交时序、重复事件。
  - 验收标准：失败不检查；成功只检查受影响关系。
  - 完成定义：链路和幂等证据齐全。
- [ ] X1813 增加单飞、重试和过期恢复
  - 前置任务：X1812。
  - 功能范围：同一依赖任务只能运行一次，支持超时和重试。
  - 代码交付物：去重键、锁/唯一索引、恢复策略。
  - UI要求：显示检查中/重试中。
  - 外部系统：不涉及。
  - 测试要求：并发、重启、重复消息、超时。
  - 验收标准：旧批次不能覆盖新批次。
  - 完成定义：故障注入通过。

## C. 关系质量引擎
- [ ] X1820 实现关系元数据安全解析
  - 前置任务：X1801。
  - 功能范围：读取真实dataset/relation元数据，白名单校验标识符。
  - 代码交付物：解析器、配置校验。
  - UI要求：不涉及UI。
  - 外部系统：不涉及。
  - 测试要求：非法标识符、键不一致、关系删除。
  - 验收标准：前端不能注入任意SQL。
  - 完成定义：安全测试通过。
- [ ] X1821 实现relation_cardinality
  - 前置任务：X1820、X1802。
  - 功能范围：支持1:1/N:1，统计右侧重复、左侧缺失、最大匹配数、哈希样例。
  - 代码交付物：质量引擎handler和PostgreSQL查询。
  - UI要求：显示计数和哈希，不显示明文。
  - 外部系统：不涉及。
  - 测试要求：通过、重复、缺失、空表、NULL、期间边界。
  - 验收标准：本次两个业务键分别识别为重复和缺失。
  - 完成定义：SQL和脱敏证据完成。
- [ ] X1822 实现关系→数据集→报表状态聚合
  - 前置任务：X1821。
  - 功能范围：状态优先级、报表扇出、旧批次保护。
  - 代码交付物：聚合与传播service。
  - UI要求：显示影响范围。
  - 外部系统：通过事件通知。
  - 测试要求：多关系、多报表、状态优先级。
  - 验收标准：关系检查次数不随报表数增加。
  - 完成定义：一致性测试完成。

## D. 依赖索引
- [ ] X1830 构建反向依赖索引
  - 前置任务：X1820。
  - 功能范围：表→数据集→关系→报表，支持重建和漂移检测。
  - 代码交付物：索引、查询、重建接口。
  - UI要求：展示授权范围的影响数量。
  - 外部系统：不涉及。
  - 测试要求：一表多数据集、一数据集多报表、删除/变更关系。
  - 验收标准：索引与事实表一致。
  - 完成定义：大数据量和一致性通过。
- [ ] X1831 实现按期间dirty与回填
  - 前置任务：X1830、X1812。
  - 功能范围：只检查受影响期间，支持补跑/重建/过期。
  - 代码交付物：dirty状态和运维命令。
  - UI要求：显示批次和pending原因。
  - 外部系统：不涉及。
  - 测试要求：多期间、无期间、重复批次、失败回填。
  - 验收标准：不扫描全历史。
  - 完成定义：回填演练完成。

## E. 报表门禁与UI
- [ ] X1840 增加报表轻量质量门禁
  - 前置任务：X1822。
  - 功能范围：查询/导出前读取状态，不扫描底层。
  - 代码交付物：门禁service、API、错误码。
  - UI要求：状态条覆盖四种状态。
  - 外部系统：不涉及。
  - 测试要求：缓存命中、缺失、阻断、管理员策略、导出。
  - 验收标准：日志无关系扫描，缺失状态安全处理。
  - 完成定义：查询、导出、直调API均验证。
- [ ] X1841 扩展数据质量UI
  - 前置任务：X1821、X1830、X1840。
  - 功能范围：关系规则、影响范围、期间状态、诊断和定时配置。
  - 代码交付物：`WarehouseQuality.vue`、API类型、组件测试。
  - UI要求：遵循`ui-interaction.md`，覆盖loading/empty/forbidden/pending/warning/failed/error/stale。
  - 外部系统：不直连UCP。
  - 测试要求：组件、权限、脱敏、构建。
  - 验收标准：管理员可配置，普通用户按授权查看，不显示敏感原值。
  - 完成定义：UI、测试、构建和人工验收完成。
- [ ] X1842 接入质量告警事件
  - 前置任务：X1822。
  - 功能范围：失败/阻断发布统一质量事件，告警去重和审计。
  - 代码交付物：事件payload、通知适配、审计。
  - UI要求：历史显示触发状态，不显示凭证。
  - 外部系统：复用既有通知基础设施，通知失败不回滚质量结果。
  - 测试要求：成功、失败重试、重复抑制、权限过滤。
  - 验收标准：质量结果与通知解耦并可追踪。
  - 完成定义：事件、通知、降级、审计完成。
