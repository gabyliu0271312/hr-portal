## 0. 冻结合同

### 0.1 功能定义

本功能是**报表级完整维度组合例外重映射**：将一个或多个当前真实存在的完整维度组合映射为一个完整结果组合；未命中规则的组合保持原样；所有基础记录只映射一次；映射后结果组合相同的数据自动汇总。

### 0.2 不可变业务规则

1. 仅适用于出数类型为“汇总表”的报表。
2. 来源只能从当前报表数据范围、当前配置人员数据权限内，归并前真实存在的完整维度组合中选择；不允许手工添加、模糊条件、通配符或部分维度。
3. 来源候选查询不受归并后的维度筛选影响；候选可达一万条以上，必须服务端搜索、分页并支持跨页选择。
4. 支持单来源重映射、多来源归并、映射到已有组合和映射到同类型新组合。
5. 结果每个维度支持：相同值自动带出、选择来源值、输入同类型自定义值。
6. 自定义值必须保持字段类型；不能自定义空值。真实存在的 `NULL`、空字符串、空白文本、数值 `0`、文本 `"0"`、布尔 `false` 必须区分。
7. 单来源映射到自身属于无效规则并阻止保存；多来源映射到其中一个来源合法。
8. 同一来源组合只能属于一条规则；禁止级联和循环；多条规则可以输出同一最终组合。
9. 规则只按原始组合命中一次，不按映射结果再次匹配；不支持优先级。
10. 归并统一作用于报表全部指标；每个指标继续执行汇总表中已有的列统计规则。
11. 执行顺序固定为：数据权限/基础范围 → 数值拆分 → 度量重映射 → 维度归并 → 归并后维度筛选 → 按最终组合汇总 → 列统计规则 → 余差收口 → 排序/分页/导出/推送。
12. “度量重映射”可与维度归并共存；“列转行”“行转列”不可与维度归并共存，保存和正式预览时阻断。
13. 归并后的维度值是筛选、分组、排序、预览、导出和推送的正式值；下钻/审计保留原始值。
14. 未命中组合保持原样，不提示；已配置但当前无数据的来源保持规则且不报错。
15. 新建规则只能选择当前存在的来源；更新时，未改动但当前已无数据的历史来源允许保留。
16. 修改维度字段集合、维度数据来源、维度类型或计算逻辑后，旧规则失效并阻止保存；仅改顺序、显示名、列宽和样式不失效。
17. 新增、删除、调整指标或修改指标统计规则不要求重配归并规则。
18. 修改/删除归并结果导致配置筛选值失效时阻止保存；不得静默删除或改写筛选。
19. 汇总表切换为明细表且仍有规则时阻止保存，要求用户显式删除全部规则；规则不得隐藏停用。
20. 历史期间永远按最新规则重算，不保留旧规则出数版本或生效日期。
21. 规则变更复用“系统设置 → 操作日志”的 `report_access/update`；只保存实际增量差异，不保存两份完整规则。
22. 审计差异支持分页和敏感值脱敏；审计写入失败不回滚报表保存。
23. 不新增菜单、页面路由或操作权限点；复用报表修改权限和操作日志权限。

### 0.3 建议配置合同

`ReportConfig` 新增 `dimension_merge_rules`，空数组表示未配置，不增加隐藏的 `enabled` 开关。

```text
DimensionMergeRule
- id: string                         # 报表内稳定 ID，用于编辑与审计差异
- name: string                       # 报表内唯一
- dimension_signature: string[]      # 当前全部维度 instance_id，顺序稳定
- sources: DimensionTuple[]          # 至少 1 个完整组合
- target: DimensionTargetTuple       # 完整结果组合

DimensionTuple
- values: Record<instance_id, typed JSON value>

DimensionTargetTuple
- values: Record<instance_id, typed JSON value>
- modes: Record<instance_id, auto | source | custom>
```

执行匹配只使用规范化后的 `values`；`modes` 仅用于配置回显和校验。规则保存于当前 `reports.config`，不建立规则版本或生效日期。

### 0.5 配置效率优化补充
