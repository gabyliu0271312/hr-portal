# 绩效模板创建页 UI 蓝图

- 来源：`https://idreamsky.feishu.cn/perf/admin/templates/create`
- 目标路由：`/performance/settings/templates/create`
- 视口基准：894x631（Tablet）
- 页面类型：挂载于 `PerformanceAdminLayout` 的全屏创建页，不渲染模板列表卡片。

## 页面结构

```text
全屏创建页
├── Header
│   ├── 返回图标 + 返回 + 新建绩效模板
│   ├── 不可点击的步骤导航
│   └── 下一步
└── 主体
    └── 基本信息表单
        ├── 名称（必填）
        ├── 描述（0/2000）
        ├── 模板语言（中文固定选中，英文可选）
        └── 配置「计算规则」（默认关闭）
            ├── 按评估内容计算
            └── 按评估角色计算
```

## 视觉基线

- 字体：系统字体，优先 `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Microsoft YaHei`。
- 页面背景：`#F5F6F7`；Header 白色、底部 `#E5E6EB` 边框。
- 主色：`#3370FF`；正文 `#1F2329`；次要文字 `#646A73`；禁用/未到达步骤 `#8F959E`；分隔箭头 `#BBBFC4`。
- 输入框：宽度约 640px、高度约 32px、边框 `#D0D3D6`、圆角 6px。
- 描述框：宽度约 640px、最小高度约 49px，右下角显示实时字数。
- 校验错误：边框和文字 `#F54A45`，错误文字 14px/21px，顶部间距 2px。
- 计算规则复选框：16px，选中态使用主色；整行可点击。
- 下一步：最小宽度 80px、高度约 32px、圆角 6px、背景 `#3370FF`、文字白色。

## 状态和交互

- 计算规则默认关闭；关闭时不显示选项、错误提示或“计算规则”步骤。
- 开启计算规则后显示两项多选，默认均未选中；至少选择一项才可下一步。
- 名称校验顺序：去首尾空格后必填校验，再与本地 Mock 名称完全匹配校验。
- 描述最大 2000 字，超出时截断；实时显示 `当前字数/2000`。
- 中文语言始终选中且不可取消；英文可选。
- 顶部步骤不可点击，只能通过“下一步”推进；本阶段只渲染基本信息，校验成功后显示流程设置占位提示。
- 基本信息页返回不二次确认且不保存；成功进入后续占位步骤时保存本地 Mock 草稿。
- 重名时显示 `该模板名称已存在，请重新输入`；规则为空时显示 `如果开启计算规则配置，则至少配置一个计算规则`。

## 实现边界

本蓝图不包含后端 API、数据库、权限、发布、真实流程配置、评价内容配置、真实计算规则配置或外部系统集成。
