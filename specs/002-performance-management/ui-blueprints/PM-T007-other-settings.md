## 5. 交互与状态

| 状态/操作 | 反馈 |
|---|---|
| 页面初始（T04） | GET 配置；加载前禁用复选框；失败显示重新加载；成功后使用数据库值 |
| 点击查看示例 | 显示轻量提示；不打开外部页面，不改变配置 |
| 点击授权提示编辑图标 | 显示“编辑提示将在下一步开放”提示；不打开弹窗 |
| 点击转交提示编辑图标 | 显示“编辑提示将在下一步开放”提示；不打开弹窗 |
| 点击复选框或标签（T04） | 只 PATCH 变化字段；保存中禁用；成功提示保存成功；失败回滚；刷新 GET 恢复已保存值。此条替代 F01 的仅内存限制，不接运行时规则 |
| 360°标签为空 | 显示“暂无 360° 评估人标签” |
| 直接无权限访问 | 由既有后台路由守卫拒绝，不渲染页面 |
| 窄屏 | 卡片内容可换行；提示文案与操作按钮不溢出页面 |
