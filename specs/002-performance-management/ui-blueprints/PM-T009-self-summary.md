# PM-T009 自我总结填写页 UI 蓝图（draft）

## 来源与边界

- 来源：用户提供的自我总结截图及 `D:\乐逗\Desktop\自我总结--去完成.txt` 捕获参数。
- 目标视口：1534×911，桌面端。
- 本期仅实现“自我总结”，OKR、翻译和全屏填写保持禁用/不实现。
- 富文本、复选框、评级选项使用现有共享组件；本页只负责模板适配和状态编排。

## 几何与视觉参数

| 区域 | 参数 |
|---|---|
| 全局头部 | 1534×64px |
| 页签容器 | 约 1510×48px，白色背景 |
| 内容卡片 | 约 1510×1048px，8px 圆角 |
| 底部操作栏 | 固定高度约 64px |
| 字体 | -apple-system，12/14/16/20px |
| 主要颜色 | `#1F2329`、`#646A73`、`#8F959E`、`#D0D3D6`、`#3370FF` |
| 间距 | 2/4/8/12/16/20/24/32/56px |

## 页面结构

```text
Header 64px
├─ 返回
└─ 用户头像 / 姓名 / 组织信息
Tabs 48px
└─ 自我总结（active） / OKR（disabled）
Scrollable card
└─ 模板 schema 动态区块
Fixed footer 64px
└─ 提交 / 取消 / 自动保存提示
```

## 状态矩阵

| 状态 | 证据/实现要求 |
|---|---|
| default | 截图主状态，白色卡片、蓝色 active tab |
| loading | 表单加载占位 |
| saving | 底部显示保存中 |
| save-error | 保留输入并提示失败 |
| validation-error | 字段红框、错误文案、滚动到首个错误 |
| submit-error | 保留输入并提示原因 |
| readonly | 截止后提交成功，控件不可编辑 |

## 变体契约

- 页面标题：`task.node_name`，不得前端写死。
- 评级选项：来自模板；选中颜色来自评估规则配置。
- 价值贡献：多选标签 + 一个共用补充输入框。
- 必填：由每个模板字段的 `required` 决定。
