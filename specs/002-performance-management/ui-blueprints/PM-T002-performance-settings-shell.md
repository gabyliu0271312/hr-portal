# PM-T002：绩效后台设置壳 UI 蓝图

- 蓝图版本：v1.0
- 对应功能：`PM-T002「绩效后台入口与设置壳」`
- 对应原子任务：`PM-T002-T02`
- 状态：已确认并已实现（2026-08-04）。
- 参考：用户提供的后台截图（仅参考布局、层级与留白；不复用“飞书绩效设置”名称及已排除菜单）。

## 1. 目标与边界

为有权限的绩效配置人员提供独立后台设置入口。用户从绩效前台右上角“后台管理”点击后，在新的浏览器 Tab 打开 `/performance/settings`；页面不复用 HR Portal 或绩效前台的顶部、侧栏和 Tab。

本任务只交付设置壳：独立顶栏、侧栏、内容区，以及各菜单的“功能建设中”占位；允许切换菜单选中态，但不创建实际配置表单、数据表、接口或保存动作。

明确不包含：

- 周期与项目、席位、绩效模板、评估题、权限管理、系统设置的实际业务功能；
- 通用设置分组和“飞书管理后台”入口；
- HR Portal 通用后台、用户资料设置和权限配置功能；
- 新的后端接口、数据库迁移或权限模型修改。

## 2. 页面与访问控制

| 项目 | 设计 |
|---|---|
| 页面名称 | 创梦绩效设置 |
| URL | `/performance/settings` |
| 打开方式 | 绩效前台右上角“后台管理”以新浏览器 Tab 打开。 |
| 页面布局 | 独立 `PerformanceAdminLayout`；不得渲染 `PerformanceLayout`。 |
| 可访问用户 | 同时具有 HR Portal `performance.admin` 菜单权限、且具备至少一项绩效内部配置权限的用户。 |
| 无权限处理 | 直接访问 URL 时沿用 T01 权限守卫，显示现有无权限/跳转逻辑；不得仅靠菜单隐藏。 |
| 独立超级管理员 | 仅可创建绩效管理员账号；不因该身份获得本页业务配置访问权限。 |

## 3. 信息架构

```text
创梦绩效设置
├─ 顶栏
│  ├─ 左：产品标识 + 创梦绩效设置
│  └─ 右：当前登录用户头像 / 用户菜单
├─ 左侧栏
│  └─ 应用设置
│     ├─ 周期与项目
│     ├─ 席位管理
│     ├─ 绩效模板
│     ├─ 评估题管理
│     ├─ 权限管理
│     └─ 系统设置
└─ 主内容区
   ├─ 当前菜单标题
   └─ “功能建设中”占位卡片
```

不出现“通用设置”分组、“飞书管理后台”跳转项，以及 HR Portal/绩效前台的顶栏、左侧导航、Tab。

## 4. 视觉与布局

- 整体背景：浅灰 `#F5F6F8`；顶栏高度 48px、深蓝 `#334A7D`；左侧栏宽 230px、白色背景；主内容内边距 20px。
- 顶栏左侧为简洁产品标识、竖向分隔线和白色文字“创梦绩效设置”；右侧只保留当前用户头像及既有用户菜单触发器。
- 侧栏分组标题为“应用设置”，不可点击。菜单行高 40px，含简洁线性图标；选中项使用浅蓝 `#DCE7FF` 背景、主蓝 `#3D6DF2` 文字。
- 默认选中“席位管理”，以对齐已确认参考图；这只决定 T02 默认占位展示，不表示席位管理先于周期与项目开发。
- 内容区顶部显示当前栏目标题；下方白色圆角卡片居中展示轻量空状态图形、文案“该功能正在建设中”和辅助说明“后续将按已确认的原子任务逐步开放”。
- 不显示假数据、表单、保存按钮、导入导出或可导致业务已可用误解的操作控件。

## 5. 交互与状态

| 编号 | 用户操作 | 系统反馈 | 范围 |
|---|---|---|---|
| I01 | 点击绩效前台“后台管理” | `window.open('/performance/settings', '_blank', 'noopener')` 打开新 Tab。 | T01 入口 + T02 承接 |
| I02 | 新 Tab 加载页面 | 通过既有 T01 双重权限守卫后渲染独立后台壳。 | T02 |
| I03 | 点击任一应用设置菜单 | 切换选中态、标题和建设中占位；不请求业务 API。 | T02 |
| I04 | 无权限直接访问 URL | 路由守卫拒绝访问，沿用现有无权限反馈/跳转。 | T01 权限复用 |
| I05 | 点击右上角头像 | 沿用既有用户菜单；不新增账户管理功能。 | 复用既有能力 |

| 状态 | 触发条件 | 页面表现 |
|---|---|---|
| 默认 | 有权限用户首次进入 | “席位管理”选中，显示对应建设中占位。 |
| 菜单切换 | 点击其他菜单 | 仅切换选中态和占位标题。 |
| 加载 | 权限上下文未返回 | 复用现有加载反馈，禁止先渲染受保护内容。 |
| 无权限 | 缺失任一 T01 所需权限 | 不渲染设置壳，执行路由守卫反馈。 |
| 鉴权错误 | 权限上下文请求失败 | 复用既有错误反馈；不降级为可访问设置页。 |

## 6. 无障碍与响应式

- 侧栏使用原生按钮或等价语义与键盘焦点样式；当前项使用 `aria-current="page"` 或等价选中态。
- 小于 960px 时，侧栏可收窄为图标栏或使用抽屉；本任务不设计移动端业务页面，但不得遮挡内容或丢失菜单入口。
- 所有占位文案使用真实文本，不仅依赖色彩区分选中状态。

## 7. 确认范围

确认本蓝图后，`PM-T002-T02` 的正式实现仅包含新 Tab 跳转、独立后台设置壳、上述六个应用设置菜单及占位内容、T01 双重权限守卫复用与测试。

确认本蓝图不等于确认任何菜单的业务功能需求。各真实配置模块仍须另行编写并确认规格与 UI 蓝图。
