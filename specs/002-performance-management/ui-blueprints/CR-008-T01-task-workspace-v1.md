## 页面和角色

| 路由 | 角色/入口 | 约束 |
|---|---|---|
| `/performance/review/self-summary` | 工作总结真实任务执行人；工作台/绩效评估进入 | 独立填写外壳，不增加业务授权 |
| `/performance/review/template-task` | 已支持的评价/校准任务执行人 | 复用同一外壳及 Renderer，不开放新任务类型 |

- 不显示门户或绩效主导航/侧栏；保留返回、人员信息、阶段页签和底部操作。
- 当前页签名称沿用流程节点名；内容画布标题优先任务返回的 `content_page_name`，未配置时回退节点名；二者不得修改内容块名称。
- 参考页签只显示任务 API 返回的合法配置；蓝图的“配置的参考内容”是示意，不默认增加 OKR 能力。

## 布局和行为

- 横向由视口决定；桌面外边距沿既有12px、卡片内边距沿30px建立基线，最终按同视口飞书测量微调，不用截图物理像素推算CSS值。
- 固定人员头与页签；底部操作区作为不收缩的布局区始终可见。仅中间主内容滚动；短内容白色画布填满剩余高度，长内容自然增长，最后字段可滚动到无遮挡的位置。
- 窄屏保留人员信息和提交/取消，必要时换行；页签可横向滚动，页面本身不得横向溢出。
- 正式页面复用富文本、评级、标签组件；蓝图工具栏仅外观占位，不代表要替换已有编辑器。
- 返回/取消保留原任务上下文和既有保存语义；不在此重定义自动保存、提交流程或已提交后可否再次编辑。
- 当前以默认铺满工作区为基线，不放一个无法使用的“全屏填写”按钮。若需要飞书的模式切换菜单，需先补采集真实菜单/切换状态，不能猜其行为。

## 状态与交互

蓝图右上选择器可演示：可编辑、长表单、整体只读、部分只读、加载中、加载失败、无权访问、无内容、保存失败、提交反馈。该选择器不进入正式页面。

- 字段必填/隐藏/只读/重复由 schema 决定；配置态允许保留隐藏项管理入口，员工态不泄露其定义与答案。
- “添加”仅在配置允许重复且可编辑时出现；正式校验复用现有逻辑。
- 加载/失败/无权限/无内容时不允许误提交；失败可重试；只读显示服务端已投影的答案。
- 保存/提交失败保留输入和可见反馈；提交中禁重复提交。蓝图提交始终禁用，不发网络请求。

## 实施边界与证据纠正

- 各环节题目、说明、选项和设置仍为局部权威。公共组件复用与上游答案引用不改变该原则；不将各环节改为同ID全局覆盖。
- 本轮不承诺“与飞书内部实现相同”；目标是与已观测的交互、布局和配置驱动机制一致，保留本地 Vue/FastAPI 与任务数据模型。
- 上一轮“评级/标签不触发自动保存”的结论不准确：当前 `PerformanceTemplateRenderer.vue` 的 `setFieldValue → updateAnswers` 已统一发出 `queue-save`。不得根据该错误结论重复补事件；离开保存与并发问题须另用可复现实测判定。
