# CR-010 结果沟通与校准展示 UI 蓝图

- 版本：v1
- 状态：按用户确认方案冻结
- 适用路由：`/performance/review`
- 角色：结果沟通处理人、项目校准人
- 入口：绩效评估 → 我团队的绩效 → 对应流程节点
- 复用原则：不新增页面外壳、不新增表格引擎，复用现有 360°反馈、上级评价成员列表、模板任务和已完成只读抽屉。

## A. 结果沟通

### 页面结构

```text
左侧绩效评估节点导航
└── 我团队的绩效
    └── 绩效结果沟通（选中）

右侧内容区
┌────────────────────────────────────────────────────────────┐
│ 绩效结果沟通                         截止时间：YYYY-MM-DD HH:mm │
├────────────────────────────────────────────────────────────┤
│ 搜索成员                         筛选        列设置           │
│ N 个结果                                                     │
├──────┬──────┬────────┬────────┬──────┬──────┬──────┬────────┤
│ 姓名 │ 状态 │截止时间│360°率  │ 序列 │ 职级 │入职日│ 部门…  │
├──────┼──────┼────────┼────────┼──────┼──────┼──────┼────────┤
│ 人员 │待完成│ 时间   │ 3/5    │ ...  │ ...  │ ...  │ ...    │
└──────┴──────┴────────┴────────┴──────┴──────┴──────┴────────┘
```

### 字段

固定展示：姓名、状态、截止时间、360°评估率、序列、职级、入职日期、所属部门、员工类型、上期职级。列设置可沿用 360°反馈表格的隐藏列能力，姓名列保持固定。

### 交互与状态

- 页面加载：显示列表加载态，不出现普通节点“去完成”空态。
- 有数据：每行可点击；行光标和公共表格样式与 360°反馈一致。
- 未完成行：点击后进入结果沟通模板任务页，携带项目、节点、任务和员工上下文。
- 已完成行：打开 `PerformanceReviewEvaluationDrawer`，只读展示结果沟通内容；关闭后保留列表、搜索、分页和滚动位置。
- 空数据：显示公共空态，不创建伪造任务。
- 接口失败：显示公共错误态和重试入口。
- 无权限/跨项目/跨员工：服务端拒绝，前端不显示越权数据。

## B. 校准

### 页面结构

```text
左侧绩效评估节点导航
└── 我团队的绩效
    └── 校准（选中）

右侧内容区
┌────────────────────────────────────────────────────────────┐
│ 校准                                   截止时间：YYYY-MM-DD HH:mm │
├────────────────────────────────────────────────────────────┤
│ 搜索成员                         筛选        列设置           │
│ N 个结果                                                     │
├──────┬──────┬────────┬────────┬──────┬──────┬──────┬────────┤
│ 姓名 │ 状态 │截止时间│绩效评级│序列  │职级  │入职日│ 部门…  │
├──────┼──────┼────────┼────────┼──────┼──────┼──────┼────────┤
│ 被校准│待完成│ 时间   │ --     │ ...  │ ...  │ ...  │ ...    │
└──────┴──────┴────────┴────────┴──────┴──────┴──────┴────────┘
```

### 交互与状态

- 列表直接消费当前用户的校准任务。
- 人员是项目配置规则命中的被校准人员，按冻结阶段任务返回。
- 点击待处理行进入对应阶段的校准模板任务。
- 点击已完成行沿用现有已完成查看/回看逻辑，不扩大校准权限。
- 空态、错误态、加载态和分页复用上级评价成员列表。
- 不允许前端根据当前组织关系重新计算人员范围。

## C. 响应式与可访问性

- 桌面端沿用现有列表页、公共横向滚动和固定姓名列。
- 窄屏保留表格横向滚动，不产生页面级横向溢出。
- 行点击支持键盘焦点和可读的状态文本；状态颜色不作为唯一信息。
- 抽屉可通过关闭按钮和 Escape 关闭，关闭后焦点回到触发行。

## D. 证据

- 结果沟通独立 PNG：`CR-010-T02-result-communication-v1.png`
- 校准独立 PNG：`CR-010-T03-calibration-v1.png`

## E. F03 字段可见性小修

结果沟通表的员工类型及其他个人信息列遵循接口 `visible_profile_fields`。授权时展示当期快照实际值；未授权时从表格和列设置中隐藏，不再保留误导空列；已授权但源值缺失显示 `--`。上期职级沿用职级权限。混合权限人员逐行裁剪，项目/节点刷新后重算可见列。此项不改变原权限配置、角色或流程，保留v1既有布局，无需新蓝图。

## F. F02 表格状态统一与360拒绝状态

通用任务表格采用6px圆点＋8px间距＋14px/22px正文，显示“待完成（#FF8800）、已完成（#62D256）、已逾期（#F54A45）”；360°反馈额外保留“已拒绝（#F54A45圆点，下移1px）”。完成与拒绝不因截止日期改为逾期；表格状态统一不修改侧栏、操作资格或流程状态。只复用同一状态组件，不新增拒绝按钮或生命周期。

## G. F04 姓名列统一

结果沟通、校准、360°反馈和360°邀请表的姓名单元格统一复用 `PerformanceMemberIdentity`：32px圆形文字头像、姓名末字作为fallback、头像后12px姓名间距、长姓名省略。该项不改变列表业务框架或数据权限。
