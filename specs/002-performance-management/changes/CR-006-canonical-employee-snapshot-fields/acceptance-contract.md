# CR-006 验收契约

1. Given 实时花名册存在权威字段，When 创建或刷新周期人员快照，Then 每个字段只从对应列写入。
2. Given `direct_supervisor` 是姓名或工号，When 构建快照，Then 解析为同快照员工编号并保留原始值。
3. Given 职位族和职位类任一为空，When 展示序列，Then 自动省略空段且不产生多余 `-`。
4. Given 周期快照已锁定，When 项目启动，Then 项目人员字段只从周期快照复制，实时花名册后续变化不影响项目。
5. Given 项目矩阵、统计、工作台或填写详情，When 读取人员字段，Then 不查询实时花名册补值。
6. Given 可见性规则隐藏字段，When API 序列化，Then 服务端不返回该字段真实值。
7. Given 权威字段缺失，When 启动需要该字段的同步，Then 明确失败，不回退到其他语义字段。

8. Given 六级组织含空级，When 周期固化及项目复制，Then 六个原子值与 `/` 分隔完整路径一致；成员列表“所属部门”取最末非空级。
9. Given 两条不同组织路径有同名叶子，When HRBP 查看，Then 只匹配授权路径的自身和后代，不允许反向祖先或跨分支。
10. Given 周期组织手工维护，When 更改某级，Then 在同一事务重新派生路径，拒绝直接写入 `organization_ref`。
11. Given 已锁定周期，When 实时组织变动，Then 周期/项目人员及树不变；仅新迁移的一次性开发数据回填例外。
