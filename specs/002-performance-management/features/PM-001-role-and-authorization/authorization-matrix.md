# PM-001 角色、权限与数据范围矩阵

## 1. 角色来源与范围

| 角色 | 来源 | 范围 | 快照规则 |
|---|---|---|---|
| 绩效超级管理员 | 系统初始化的纯系统账号 | 全绩效系统，但仅管理绩效管理员账号 | 不适用 |
| 绩效管理员 | HR Portal 配置或超级管理员创建 | 授权范围 | 静态授权按有效期；周期动作仍受周期范围约束 |
| 被评估人 | 周期参与人员 | 本人 | 周期锁定后固化 |
| 直属上级 | 员工直属汇报关系 | 直属下属 | 周期锁定后固化 |
| 间接上级 | 汇报关系链 | 全部下级 | 周期锁定后固化 |
| 360°评估人 | 本人邀请、直属上级添加或 HRBP 添加 | 被指派的被评估人 | 指派在周期锁定后固化 |
| 校准人 | 管理员配置校准组 | 校准组 | 周期锁定后固化 |
| HRBP | 员工信息同步的负责范围 | 负责组织及人员 | 周期锁定后固化 |
| 绩效项目管理员 | 项目级显式授权 | 单个绩效项目 | 项目关系按周期锁定 |
| 申诉处理人 | 周期启动时按人/角色配置 | 被配置范围 | 周期启动配置快照 |
| 结果发布人 | 直属上级或 HRBP 转交的临时处理人 | 具体员工、具体周期 | 原直属关系快照不变；转交单独审计 |

## 3. 特殊规则

- 员工只可看到自己邀请的360°评估人名单；上级或 HRBP 添加的评估人名单不可见。
- 360°邀请无需审批、不可拒绝、不可撤销。
- 校准调整无需人工原因，但必须自动审计。
- 结果发布后立即对员工可见且不可撤回。
- HRBP 不得直接发布结果；HRBP 仅在直属上级无法处理时转交具体发布任务。
