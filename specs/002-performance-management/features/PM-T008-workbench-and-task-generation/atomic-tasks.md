- [ ] PM-T008-T01 冻结项目成员、节点快照与任务数据契约

  - 类型：契约/迁移/数据库
  - 前置条件：PM-T003 项目与流程配置契约；Q5；迁移 head 核对
  - 必读：PM-T008 全部文档、基线 `data-model.md`、`integration.md`、`ADR-002`、迁移协调规范
  - 允许修改：PM-T008 `data-model.md`、新增 PM-T008 迁移及模型文件
  - 禁止修改：已有迁移、无关功能模型、业务前端
  - 输入/输出：输入项目规则、周期快照、节点配置；输出冻结 DTO/表字段/索引/升级降级契约
  - API/权限/外部系统：不新增外部系统；记录启动审计与个人查询授权边界

- [ ] PM-T008-T02 项目启动并生成任务服务/API

  - 类型：后端/API/权限/审计
  - 前置条件：T01；Q2、Q3、Q4、Q5；PM-T003 启动入口
  - 必读：项目 router/service/model、权限模型、执行契约、API/数据契约

  - 输入/输出：输入项目 ID和授权上下文；输出冻结后的启动响应、生成摘要、稳定错误码
  - 测试：成功、无被评估人、无效节点、360°事件时间窗口与处理人权限、复议人员优先级、重复/并发、回滚、越权和历史项目兼容

  - 非范围：具体评价、结果查看、复议表单
