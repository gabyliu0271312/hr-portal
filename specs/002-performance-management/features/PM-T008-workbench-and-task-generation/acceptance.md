# PM-T008 验收契约（草案）

本文件的已确认验收仅覆盖用户明确提出的行为；Q1–Q6 未解除前，相关条目保持待确认，不得标记通过。

## 已确认 Given/When/Then

- Given 项目为草稿且已维护项目信息模块的被评估人筛选与流程节点；When 授权管理员点击启动；Then 项目进入“进行中”，并进入任务生成事务。
- Given 项目启动任务生成成功；When 用户打开工作台；Then 项目筛选和待办读取已持久化的项目/任务记录，而不是前端 fixture 或实时重新计算结果。
- Given 用户参与项目；When 打开顶部筛选框；Then 显示周期名称、周期开始时间和周期结束时间。
- Given 项目存在节点时间配置；When 打开工作台；Then 顶部流程节点时间取项目维护值。
- Given 已启动项目的上级评估节点原定未来开始；When 授权管理员将开始时间改至当前时间之前并保存；Then 重新进入绩效评估和工作台时状态、时间轴按新时间计算，任务实际操作权限和详情截止时间按项目当前配置判断，启动时的节点/任务快照不变；已提交且超过新截止时间的任务保持只读。
- Given 结果查看和结果复议存在于项目流程；When 打开工作台顶部时间轴；Then 二者不展示为时间轴节点。
- Given 结果查看节点已配置且结果已发布；When 用户打开工作台；Then 展示独立的“查看绩效结果”卡片，点击“查看”跳转至“绩效评估 → 查看绩效结果”。
- Given 结果尚未发布；When 用户打开工作台；Then 不展示“查看绩效结果”卡片。
- Given 结果查看卡片已展示；When 用户查看“我的待办”；Then 结果查看不出现在待完成或已完成任务列表中。
- Given 用户存在任务；When 切换“待完成”和“已完成”；Then 页面分别读取任务查询结果，不以前端临时状态伪造完成。
- Given 任务尚未完成且已超过截止时间；When 查询“待完成”；Then 任务仍在“待完成”中，并显示逾期提示。
- Given 任务已实际完成；When 查询“已完成”；Then 任务出现在“已完成”中，不再出现在“待完成”中。
- Given 同一流程节点有多个待处理对象；When 用户打开“待完成”；Then 节点聚合为一条待办，并显示待处理人数，例如“上级评价（待评价 5 人）”。
- Given 用户点击节点聚合待办；When 页面跳转；Then 进入该节点对应的人员列表，而不是直接伪造完成节点。
- Given 工作台已选择项目 A；When 用户进入绩效评估；Then 绩效评估默认选择项目 A，不回退到项目列表第一项。
- Given 绩效评估切换到项目 B；When 用户进入工作台；Then 工作台默认选择项目 B。
- Given 用户从绩效评估进入任务填写页；When 点击返回且项目未变化；Then 立即恢复原项目和已选节点，不展示周期重新加载态，并在后台静默刷新任务状态。
- Given 用户在同一项目中有多个参与身份；When 打开“我的待办”；Then 所有身份对应任务合并展示，并按流程节点聚合，不要求切换身份。
- Given 360°邀请节点已开放且用户是被评估人；When 用户发起邀请；Then 系统校验节点时间和权限，并记录邀请事件，不在项目启动时预生成未确认的后续评价任务。
- Given 360°确认节点已开放且用户属于节点维护的确认人员；When 用户处理邀请；Then 系统校验节点时间和权限，确认成功后按事件结果生成后续任务。
- Given 结果复议模板节点可解析执行人；When 进入复议任务分配流程；Then 优先采用模板节点勾选的环节执行人。
- Given 结果已发布且被评估人未提交复议；When 查询待办；Then 不生成也不展示复议处理聚合项。
- Given 结果已发布且被评估人成功提交复议；When 复议申请事务完成；Then 按模板执行人优先、项目兜底人员次优规则生成复议处理任务。
- Given 模板规则无法找到有效复议处理人且项目配置了兜底人员；When 进入复议任务分配流程；Then 使用项目配置人员。

## 待确认验收

- 启动无被评估人时是否统一返回 `NO_ASSESSEES` 并保持草稿。
- 复议处理人配置按一期有效配置前提处理，不验收模板和项目兜底均无法解析的异常分支。
- 重复/并发启动的幂等响应和任务唯一性（Q5）。
- 未开放任务是否展示操作按钮；节点聚合条目的排序和逾期计数展示（Q2）。
- 360°动态处理人、多执行人和后续补任务（Q3）。
- 个人参与项目的范围、排序、默认选择和快捷入口目标（Q1/Q6）。
