# PM-T007 其他设置页面交互说明

## 页面与入口

- 路由：`/performance/settings/system/other`
- 页面标题：其他设置
- 入口：绩效后台 → 系统设置 → 其他设置
- 访问控制：复用绩效后台现有路由守卫，不新增菜单或入口权限。

## 视觉基线

- 页面背景沿用绩效后台内容区背景。
- 内容最大宽度和卡片宽度以现有后台布局为准；采集桌面基线为 1534×911。
- 页面标题 18px/26px/600，底部间距 16px。
- 卡片白底、8px 圆角、20px 内边距、16px 卡片间距。
- 文本颜色沿用 token：主文本 `#1F2329`，次文本 `#646A73`，主色 `#3370FF` / `#1456F0`，浅灰内容块 `#F5F6F7`。
- 禁止新增旧版 `brand/ink/hp` token。

## 状态与反馈

- T04 页面加载：GET `/api/v1/performance/system-settings/other` 读取数据库配置；加载未完成时禁用八个复选框，防止默认值覆盖真实设置。
- 空态：360°标签列表显示“暂无 360° 评估人标签”。
- T04 加载错误态：保留布局，显示加载失败与“重新加载”，未成功加载前禁止保存。
- T04 保存交互：修改仅 PATCH 一个具名字段；保存过程中禁用八项，成功提示“保存成功”，失败回滚到最后确认值并提示失败。刷新/重进通过 GET 回读数据库，不再恢复采集默认值。无 U 权限保持禁用；后端读写均要求 `performance.configuration.manage`。该规则替代上方 F01 的仅内存行为，不接入校准、结果开放或逾期等运行时规则。
- 手动开通联动：`manual_result_opening_enabled=false` 时，新建项目流程设置中的“手动开通”复选项不可选，使用全局 disabled token；禁用说明使用 `PerformanceDisabledReason` 的 token 化提示框，文案为“组织内暂不允许手动开通绩效结果”。已有项目已选状态继续展示且可保留，实际手动开通接口不读取该全局设置。系统设置读取未完成或失败时，新建项目选项保持禁用，并提供重新加载入口。
- 无权限态：不渲染页面，由路由守卫处理。
- 编辑待办态：使用 Element Plus 消息提示，不声称业务完成。
