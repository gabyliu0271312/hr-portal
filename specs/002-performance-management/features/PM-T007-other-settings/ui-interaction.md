# PM-T007 其他设置页面交互说明

## 页面与入口

- 路由：`/performance/settings/system/other`
- 页面标题：其他设置
- 入口：绩效后台 → 系统设置 → 其他设置
- 访问控制：复用绩效后台现有路由守卫，不新增菜单或入口权限。

## 视觉基线

- 页面背景沿用绩效后台内容区背景。
- 内容最大宽度和卡片宽度以现有后台布局为准；采集桌面基线为 1534×911。
- 页面标题 18px/26px/600，底部间距 16px。
- 卡片白底、8px 圆角、20px 内边距、16px 卡片间距。
- 文本颜色沿用 token：主文本 `#1F2329`，次文本 `#646A73`，主色 `#3370FF` / `#1456F0`，浅灰内容块 `#F5F6F7`。
- 禁止新增旧版 `brand/ink/hp` token。

## 第一张卡片：授权和转交设置（不含校准）

结构：

1. 卡片标题：授权和转交设置（不含校准）
2. 子标题：提示设置
3. 链接：查看示例
4. 浅灰提示容器
5. 授权提示行
6. 转交提示行
7. 每行右侧编辑图标按钮

交互：

- “查看示例”本期只显示轻量提示，不跳转外部页面。
- 编辑图标本期只显示“编辑提示将在下一步开放”的提示，不打开弹窗、不保存。
- 查看示例使用 `PerformancePermissionButton` 的 V 权限；两处编辑和标签设置图标使用同一封装的 U 权限。无 U 权限时隐藏图标，不仅靠点击时判断。
- 两条提示文案均为采集文件中的默认文案。
- 编辑按钮必须有 `aria-label`，键盘可聚焦。

## 其余卡片

按采集文件顺序尽量还原：

- 授权校准设置：复选框 + 说明文案；本期展示采集默认选中态。
- 校准导入设置：复选框 + 说明文案；本期展示采集默认选中态。
- 绩效系数设置：复选框 + 说明文案；本期展示采集默认未选中态。
- 360˚ 评估设置：标题、标签管理说明、选中的只读复选框（依照采集 HTML，不使用滑动开关）、浅灰标签区域、设置图标、暂无标签空态。
- 手动开通绩效结果：说明文案 + 复选框；本期展示采集默认选中态。
- 任务逾期限制：三组复选框和对应说明文案；本期展示采集默认选中/未选中态。

2026-10-20 用户补充修订（PM-T007-T01-F01）：8 个复选框全部支持勾选、取消及点击标签切换，父页面持有状态并通过 v-model 传递；仅当前页面内存状态，刷新后回到采集默认值，不调用保存 API，不改变实际业务规则。此条替代前述只读限制。

文案补齐：

- 查看示例前显示“可设置前台授权或转交时显示的提示文案”。
- 授权提示、转交提示的编辑图标后均显示“编辑”。
- 360° 设置图标后显示“管理标签”。
- 任务逾期最后一项说明完整显示“勾选后，可在周期设置关闭逾期任务提交机会”，仅“周期设置”沿用蓝色。

## 状态与反馈

- T04 页面加载：GET `/api/v1/performance/system-settings/other` 读取数据库配置；加载未完成时禁用八个复选框，防止默认值覆盖真实设置。
- 空态：360°标签列表显示“暂无 360° 评估人标签”。
- T04 加载错误态：保留布局，显示加载失败与“重新加载”，未成功加载前禁止保存。
- T04 保存交互：修改仅 PATCH 一个具名字段；保存过程中禁用八项，成功提示“保存成功”，失败回滚到最后确认值并提示失败。刷新/重进通过 GET 回读数据库，不再恢复采集默认值。无 U 权限保持禁用；后端读写均要求 `performance.configuration.manage`。该规则替代上方 F01 的仅内存行为，不接入校准、结果开放或逾期等运行时规则。
- 手动开通联动：`manual_result_opening_enabled=false` 时，新建项目流程设置中的“手动开通”复选项不可选，使用全局 disabled token；禁用说明使用 `PerformanceDisabledReason` 的 token 化提示框，文案为“组织内暂不允许手动开通绩效结果”。已有项目已选状态继续展示且可保留，实际手动开通接口不读取该全局设置。系统设置读取未完成或失败时，新建项目选项保持禁用，并提供重新加载入口。
- 无权限态：不渲染页面，由路由守卫处理。
- 编辑待办态：使用 Element Plus 消息提示，不声称业务完成。

## 组件约束

页面只负责组合组件，业务块必须放到 `frontend/src/components/performance/`。单文件超过 200 行需继续拆分。第一张卡片不得与其他卡片共用一份页面内联业务结构。
