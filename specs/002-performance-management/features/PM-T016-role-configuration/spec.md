## 1. 本轮范围

根据已提供的角色配置列表采集参数，实现后台「应用设置 → 权限管理 → 角色配置」的页面框架：

- 管理角色 / 评估角色页签；
- 角色名称搜索框；
- 新建、筛选、导入工具栏入口的视觉和交互占位；
- 角色、描述、状态、更新人、最近更新时间、操作列表格；
- 分页容器和空状态结构；
- 从绩效后台路由进入页面。

## 2. 明确非范围

- 不根据列表采集结果推断新建角色字段；
- 不实现编辑角色表单和权限矩阵；
- 不实现停用、删除、导入和保存接口；
- 不新增数据库迁移、后端 API 或绩效角色权限规则；
- 不宣称像素级还原通过。

## 3. 已实现基础保存

- 角色列表从 `/performance/permission-settings/roles` 读取真实数据。
- 新建角色提交角色名称、描述和功能权限选项到同一 API。
- 后端生成内部 `custom.*` 角色编码并写入 `performance_roles`。
- 功能权限选项当前只持久化选择结果，暂不映射到 `PerformancePermission`。
- 创建成功写入 `PERFORMANCE_ROLE_CREATED` 审计事件。
- 角色名称重复时返回 409，名称为空时由 Schema 拒绝。
