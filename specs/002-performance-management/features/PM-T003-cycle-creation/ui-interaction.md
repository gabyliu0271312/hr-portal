# PM-T003 周期创建最小交互说明

## 1. 入口与页面

- 入口：`/performance/settings` 左侧“周期与项目”。
- 列表页：左侧周期列表，右侧当前周期详情。
- 新建页：点击周期列表右侧加号，进入“新建周期”。
- 编辑页：周期操作菜单点击“编辑”，复用新建表单并回填数据。
- 返回：返回周期列表，未保存变更时提示确认。

## 2. 周期基础信息

| 字段 | 类型 | 必填 | 规则 |
|---|---|---:|---|
| 语言 | 预留选择 | 是 | 一期只启用中文，保留字段以便未来扩展 |
| 周期名称 | 文本 | 是 | 完全手工填写 |
| 年份 | 年份选择器 | 是 | 年份面板支持右上角翻页，不将单页年份视为固定范围 |
| 周期类型 | 分组选择 | 是 | 年度、半年度、季度、双月、月度、非标准周期/自定义 |
| 周期起止时间 | 日期时间范围 | 是 | 标准类型自动带出，可手动修改；自定义完全手填 |

保存校验：

- 点击保存时，所有已启用的必填字段统一执行字段级校验；未填写字段显示公共错误边框 Token，并在控件下方显示“字段名为必填”红色文案。
- 校验错误首次出现后，用户修改对应字段时清除该字段错误；动态隐藏的字段不参与校验。
- 错误边框和错误文案使用 `--performance-field-border-invalid`、`--performance-field-error-color`、`--performance-field-error-font-size` 和 `--performance-field-error-line-height`。
- 周期名称不能为空。
- 年份和周期类型不能为空。
- 开始时间和截止时间不能为空。
- 截止时间必须晚于开始时间；错误字段下展示“需晚于开始时间”。
- 不校验周期重复和时间重叠。

## 3. 人员和部门信息设置

锁定规则为必填单选：

- 新建周期时，立即锁定。
- 新建周期并到达指定时间后，再锁定。

选择定时锁定时：

- 展示锁定时间日期时间选择器，精确到小时和分钟。
- 锁定时间必须晚于当前时间至少 6 小时。
- 当前时间为 2026 年 8 月 7 日时，示例错误提示为“锁定时间必须比当前时间晚至少 6 小时”。
- 历史周期允许定时锁定，不要求锁定时间早于周期开始时间。
- 创建成功后锁定规则和锁定时间不可修改。

锁定前名单规则为周期级配置：

- 不自动变化，由管理员手动调整。
- 指定时间前，系统每天定时自动调整。
- 自动调整不得覆盖已经手动维护过的周期名单。

锁定后、绩效环节开始前，仅周期管理员可更新锁定人员与部门信息；保存必须填写原因并产生审计记录。项目管理员本期仅查看其授权项目范围内的周期详情和项目壳，不读取或维护周期全局人员快照。

## 4. 离职人员参评设置

- 开关关闭：已离职人员不进入本周期人员快照。
- 开关开启：展示离职日期范围和参评方式，日期范围必填。
- 离职日期范围首尾均包含，按实际离职生效日期判断。
- 参评方式：生成评估任务并纳入报表统计；不生成评估任务，仅纳入报表统计。
- 该设置属于周期级配置；项目创建和项目选人不在本交互说明中实现。


## 5. 评估设置

- “评估设置”下的“绩效模板”选择项从现有绩效模板列表接口获取，只展示状态为 `active`（已启用）的绩效模板；弹层每条分两行展示名称与说明。加载失败、无已启用模板时分别提示，不使用演示数据。
- 新建与编辑周期通过 `template_id` 提交所选模板，服务端仅接受 `performance` 类型且状态为 `active` 的模板；既有周期的 `template_id` 可为空，重新进入编辑时回填所选模板。当前绑定模板被停用时，编辑页不得默默清除；需重新选择已启用模板后再保存。此处只保存关联，不触发项目任务或改写已启动项目快照。
- 绩效模板下方展示“评估结果校验提示规则”标题。
- 标题下展示灰色规则卡片：
  - 标题：“不同评估环节的评估结果差异提示”；
  - 说明：“可设置当不同环节中相同评估项的评估结果有一定差异时，会触发差异提示。”；
  - 底部展示 14px 蓝色加号图标与按钮文案“添加需对比的环节”。
- 当前已实现“添加需对比的环节”右侧抽屉：复用统一 `PerformanceDrawerShell` 与 `PerformanceDrawerFooter`；支持选择两个不同评估环节、动态添加/删除评估项差异规则、阈值输入、三种提示方式多选、字段校验和提交回写周期草稿。
- 规则数据仅在周期表单草稿中维护，周期最终保存仍由页面底部“保存”统一提交；模板接口未接入时使用默认评估环节选项，正式接入后由页面传入真实选项。
- 规则卡片使用全局 `--performance-evaluation-rule-surface`（`#F8F9FA`），圆角与间距复用全局设计 token；标题复用全局正文色与 14px 字号，说明复用 `--performance-count-badge-text`，加号和文案复用 `--performance-button-text-color`。


周期详情页在基础信息下展示“项目设置”区域，属于本期 UI 信息架构范围，但不实现项目业务配置。

- 项目设置标题和“新建”按钮：按钮保留为后续项目配置入口。
- 右侧提供通过项目名称搜索和筛选入口。
- 表格字段固定为：项目名称、描述、项目管理员、状态、评估人数、操作。
- 操作列固定在表格右侧，不随横向滚动离开视口。
- 当表格宽度超过内容区时，在表格底部展示横向滚动条。
- 底部保留分页信息、上一页/下一页、当前页和每页条数选择。
- 操作列展示编辑、启动和更多入口；更多菜单包含复制、删除。
- 本期只展示操作入口及其状态，不提交项目业务请求；实际动作由下一项项目配置需求实现。
- 状态和评估人数属于只读展示字段；具体数据接口由项目功能需求定义。

外层页面必须保持周期详情与项目列表的上下文关系，不能把项目列表提前拆成独立一级后台菜单。

分割线布局（2026-10-15 按目标采集校准）：周期内容宽 208px，右侧留白 20px，详情左侧留白 20px；分割线为 1px、`rgba(187, 191, 196, 0.5)`，上下延伸白色容器内边距各 20px。工作区随白色容器撑高，空态也保持全高；在 1534×911 视口下线高为 773px，不固定其他视口高度。
## 7. 列表操作与删除

- 周期列表支持搜索和周期选择。
- 操作菜单包含编辑和删除。
- 周期内存在已启动项目时，删除按钮置灰。
- 无项目或仅有未启动项目时，点击删除弹出确认框：
  - 标题：“确定要删除周期吗？”
  - 内容：“删除后，周期内的所有项目将同步删除，请谨慎操作。”
  - 操作：“保留”“删除”。
  - 使用共享 `PerformanceConfirmDialog` 和 `PerformanceWarningFilledIcon`：遮罩、图层、图标、按钮及 hover 状态由公共设计 token 控制；业务删除请求由页面的确认回调执行。
  - 弹窗常规宽度固定为 420px（小屏收缩至视口减 32px），标题/说明按内容自动换行决定高度；正文过长时内部滚动，强确认变体才使用 600px，不为每处删除单独定义宽高。
- 删除成功后返回列表并刷新；失败保留当前页面并展示错误原因。

## 8. 页面状态

| 状态 | 页面表现 |
|---|---|
| 加载中 | 表单骨架或加载反馈，禁止重复提交 |
| 空周期列表 | 展示空态和“新建周期”入口 |
| 保存中 | 保存按钮禁用并显示处理中 |
| 保存成功 | 返回周期详情或列表，展示成功反馈 |
| 校验失败 | 字段级红色错误文案，保留用户输入 |
| 接口失败 | 展示错误反馈，不清空表单 |
| 无权限 | 不渲染业务内容，沿用后台路由权限反馈 |

## 10. 项目人员范围选择交互修订（2026-10-16）

- 新建项目的限定考核范围、项目信息中的被评估人筛选，复用同一个范围规则组件；部门值选择继续使用 HRBP 权限管理的组织树选择器，员工值选择继续使用绩效人员选择器。
- 新增空条件的字段选择框展示“请选择范围”，不预选部门；最右侧条件值选择框始终占位显示，未选字段时展示禁用的“请选择”框，选择“部门/员工”（被评估人还可选择人员类型）后在原位置切换为对应的值选择器。
- 打开新建项目弹窗和进入项目设置页时，不请求周期范围选项；点击部门、员工或人员类型的值选择框后，调用已有 `evaluator-options` 接口加载选项；已选条件只回显已保存的值，不因加载选项改变选中状态。
- 保持原被评估人模块的字段、操作符、值选择顺序及添加范围/条件行为。没有选定字段或没有选择条件值时，保存阶段阻止提交。
- 接口失败保持当前选择和表单输入，允许再次点击重试；禁止空接口结果或加载完成事件自动选中第一个部门。
- 开关位置：开关紧跟“限定考核范围”标题，位于标题右侧，使用全局 `PerformanceSwitch` 和 switch token；说明文案“开启后，只能在限定范围内圈选被评估人”置于标题行下方。
- 规则卡片下方的新增操作显示为带 14px 加号图标的“添加条件”文字按钮，使用全局 `PerformanceTextButton` 与按钮文字 token；不使用“添加人员范围”文案。
- 初始三列选择框均保持白色卡片表面：未选字段时操作符和值框虽不可交互，但禁用态只影响交互、不使用灰底；通过共享 `PerformanceSelectShell` 的白色禁用表面变体控制，不改变其他场景的默认灰色禁用态。
- 条件连接符复用修订（2026-10-19）：限定考核范围保持已确认的左侧贯穿多行“或”轨道、条件行直接子节点、宽度和删除按钮结构不变；被评估人组内两条及以上条件使用同款左侧轨道，文案为“且”，条件组之间恢复原有的横向分隔线和“或”文本，不使用组内竖向框选；只在条件数大于一时显示条件删除、组数大于一时显示条件组删除。校准规则的校准人和指定校准范围同样使用组内“且”竖线、组间横向“或”分隔以及两级删除，至少保留一组和每组一条条件。校准条件组配置保存不等同于运行时校准人分配。
- 采集稿对齐（2026-10-16）：开关打开后在 600px 项目弹窗的内容区展示浅灰色规则卡片，卡片内边距 20px、圆角 8px；顶部左“人员范围”右“满足以下任一条件”。单行按 128px 字段、88px 操作符、剩余空间值选择框与 8px 间隔排布，控件高 32px。底部使用共享文字按钮承载单独的加号图标，新增规则后右侧值框缩短并显示该行删除图标；多行左侧显示“或”连线。卡片仅用于限定考核范围，不改变项目“被评估人”编辑器的原有分组模式；灰底、文字、蓝色和边框均复用设计 token。

## 9. 明确不包含

- 项目新建/编辑表单、项目成员和项目管理员配置、项目启动/复制/删除业务、项目权重和项目评价。
- 项目成员重复归属校验。
- 流程模板、评价模板和绩效任务配置。
