# PM-T003 周期创建最小交互说明

## 1. 入口与页面

- 入口：`/performance/settings` 左侧“周期与项目”。
- 列表页：左侧周期列表，右侧当前周期详情。
- 新建页：点击周期列表右侧加号，进入“新建周期”。
- 编辑页：周期操作菜单点击“编辑”，复用新建表单并回填数据。
- 返回：返回周期列表，未保存变更时提示确认。

## 2. 周期基础信息

| 字段 | 类型 | 必填 | 规则 |
|---|---|---:|---|
| 语言 | 预留选择 | 是 | 一期只启用中文，保留字段以便未来扩展 |
| 周期名称 | 文本 | 是 | 完全手工填写 |
| 年份 | 年份选择器 | 是 | 年份面板支持右上角翻页，不将单页年份视为固定范围 |
| 周期类型 | 分组选择 | 是 | 年度、半年度、季度、双月、月度、非标准周期/自定义 |
| 周期起止时间 | 日期时间范围 | 是 | 标准类型自动带出，可手动修改；自定义完全手填 |

保存校验：

- 周期名称不能为空。
- 年份和周期类型不能为空。
- 开始时间和截止时间不能为空。
- 截止时间必须晚于开始时间；错误字段下展示“需晚于开始时间”。
- 不校验周期重复和时间重叠。

## 3. 人员和部门信息设置

锁定规则为必填单选：

- 新建周期时，立即锁定。
- 新建周期并到达指定时间后，再锁定。

选择定时锁定时：

- 展示锁定时间日期时间选择器，精确到小时和分钟。
- 锁定时间必须晚于当前时间至少 6 小时。
- 当前时间为 2026 年 8 月 7 日时，示例错误提示为“锁定时间必须比当前时间晚至少 6 小时”。
- 历史周期允许定时锁定，不要求锁定时间早于周期开始时间。
- 创建成功后锁定规则和锁定时间不可修改。

锁定前名单规则为周期级配置：

- 不自动变化，由管理员手动调整。
- 指定时间前，系统每天定时自动调整。
- 自动调整不得覆盖已经手动维护过的周期名单。

锁定后、绩效环节开始前，仅周期管理员可更新锁定人员与部门信息；保存必须填写原因并产生审计记录。项目管理员本期仅查看其授权项目范围内的周期详情和项目壳，不读取或维护周期全局人员快照。

## 4. 离职人员参评设置

- 开关关闭：已离职人员不进入本周期人员快照。
- 开关开启：展示离职日期范围和参评方式，日期范围必填。
- 离职日期范围首尾均包含，按实际离职生效日期判断。
- 参评方式：生成评估任务并纳入报表统计；不生成评估任务，仅纳入报表统计。
- 该设置属于周期级配置；项目创建和项目选人不在本交互说明中实现。


## 6. 周期详情外层与项目列表 UI 壳

周期详情页在基础信息下展示“项目设置”区域，属于本期 UI 信息架构范围，但不实现项目业务配置。

- 项目设置标题和“新建”按钮：点击进入项目设置新建页，保存后进入项目设置详情页。
- 项目设置页 Head 复用绩效模板新建页的全屏头部结构，步骤固定为“项目信息、流程设置、起止时间”。
- 项目设置页真实加载第一步选择的已启用绩效模板 workflow，按模板顺序展示最多 9 类节点；每张节点卡片显示模板节点名称、描述、执行人和对应 `PerformanceWorkflowStageIcon` 图标，不新增模板未返回的节点。
- 360°邀请节点显示默认邀请、最少邀请人数、推荐邀请、是否允许自愿评估及“设置”编辑入口；校准节点显示强制/建议分布开关、阶段和校准规则；绩效结果查看节点显示自动/手动开通方式；结果复议节点显示兜底处理人。上述配置通过项目 PATCH 保存并在重新打开时回填。
- 被评估人规则支持同组条件“且”、不同组“或”，条件支持部门、人员类型、员工，操作支持包含和不包含。
- 项目详情右上角“编辑”进入同一项目设置页并回填已保存配置。

外层页面必须保持周期详情与项目列表的上下文关系，不能把项目列表提前拆成独立一级后台菜单。
## 7. HRBP 权限管理

入口：周期详情右上角“设置”→“HRBP 权限管理”→“添加 HRBP”。

- “HRBP”选项来自当前周期可用人员；“权限范围”保留组织树选择。
- 开启“设置不可见人员”后，不可见人员选项必须来自当前周期人员快照，展示姓名和工号，不读取实时花名册替代快照。
- 点击“确定”调用周期级 HRBP 权限保存 API；保存成功后关闭弹窗、刷新列表并展示成功反馈；失败保留弹窗内容并展示接口错误。
- 每个周期同一 HRBP 只能有一条配置；编辑和删除均调用真实 API。
- 保存的不可见人员只影响该 HRBP 在项目管理中的成员列表、矩阵分析和统计报表展示，不从周期快照或项目成员快照中删除人员。

## 8. 列表操作与删除

- 周期列表支持搜索和周期选择。
- 操作菜单包含编辑和删除。
- 周期内存在已启动项目时，删除按钮置灰。
- 无项目或仅有未启动项目时，点击删除弹出确认框：
  - 标题：“确定要删除周期吗？”
  - 内容：“删除后，周期内的所有项目将同步删除，请谨慎操作。”
  - 操作：“保留”“删除”。
- 删除成功后返回列表并刷新；失败保留当前页面并展示错误原因。

## 9. 页面状态

| 状态 | 页面表现 |
|---|---|
| 加载中 | 表单骨架或加载反馈，禁止重复提交 |
| 空周期列表 | 展示空态和“新建周期”入口 |
| 保存中 | 保存按钮禁用并显示处理中 |
| 保存成功 | 返回周期详情或列表，展示成功反馈 |
| 校验失败 | 字段级红色错误文案，保留用户输入 |
| 接口失败 | 展示错误反馈，不清空表单 |
| 无权限 | 不渲染业务内容，沿用后台路由权限反馈 |

## 10. 明确不包含

- 项目新建/编辑表单中的项目流程设置编辑、项目成员和项目管理员配置、项目启动/复制/删除业务、项目权重和项目评价。
- 项目成员重复归属校验。
- 流程模板、评价模板和绩效任务配置。
