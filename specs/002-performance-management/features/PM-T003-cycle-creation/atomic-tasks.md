# PM-T003 原子任务：周期创建与周期级人员设置

## 任务状态规则

本文件任务均为后续实现任务。只有代码、UI、测试、验收和证据均完成后，才能将 `[ ]` 改为 `[x]`。

## 任务清单

- [ ] PM-T003-I01 实现周期列表与周期详情
  - 前置任务：PM-T003 规格与 UI 蓝图确认
  - 功能范围：周期搜索、选择、详情摘要、项目列表及项目基础操作 UI。
  - 代码交付物：前端页面、路由视图、周期/项目列表 API 对接。
  - 不修改范围：不实现项目成员、权重、评价和任务业务。
  - UI 要求：按 `../../ui-blueprints/PM-T003-cycle-creation.md` 实现双栏布局和状态。
  - 数据库要求：复用已确认模型；不得绕过迁移。
  - 权限要求：复用后台入口门禁，服务端按周期查看/管理权限校验。
  - 测试要求：列表、搜索、空态、加载态、错误态、无权限和删除按钮状态。
  - 验收标准：展示周期基本信息和项目列表字段；操作列固定、横向滚动条可见；已启动项目时周期删除按钮置灰，其他情况可进入二次确认。
  - 完成证据：测试结果、浏览器截图和 API 响应。
  - 完成定义：前后端权限和页面状态均通过验收。

- [ ] PM-T003-I06 实现周期项目基础操作
  - 前置条件：PM-T003-I01
  - 功能范围：项目新建、编辑名称/描述/管理员、项目设置页、绩效模板选择、项目起止时间、被评估人筛选、项目流程设置、启动、复制、删除；启动后的成员快照和任务生成遵循 PM-T008；列表操作列固定并按权限显示，更多菜单悬停后展示复制和删除。
  - 流程设置契约：第一步选择模板后调用模板 workflow API；按返回顺序渲染最多 9 个节点并复用模板节点图标。360°邀请、校准、结果查看、结果复议配置写入项目 `settings.flow_settings.node_settings`，与项目基础信息同一 PATCH 保存，编辑重开从项目 GET 回填。
  - 代码交付物：项目 CRUD/状态 API、项目基础数据迁移、项目操作组件和表单弹窗。
  - 不修改范围：不实现项目成员业务规则、项目权重、项目评价、评价任务详情或最终结果计算；项目启动调用 PM-T008 的成员快照与任务生成契约。
  - UI 要求：列顺序固定为项目名称、描述、项目管理员、状态、评估人数、操作；编辑/启动常驻，复制/删除在更多菜单；已启动项目删除置灰。
  - 数据库要求：项目引用唯一；创建、复制、删除事务化；删除已启动项目必须拒绝；操作写入审计。
  - 权限要求：周期管理员管理全部项目；项目管理员只能管理授权项目；普通用户无项目操作权限。
  - 测试要求：新建、编辑、启动接口契约委托 PM-T008 覆盖任务生成与幂等；本任务覆盖复制、删除草稿、拒绝删除已启动、项目范围越权、接口错误和刷新后读取。
  - 验收标准：按钮均触发真实 API；成功后列表和周期详情刷新；失败保留页面并展示原因。
  - 完成证据：前端测试、后端 API/服务测试、迁移检查、构建和浏览器操作截图。
  - 完成定义：项目基础操作、权限、持久化、审计和错误恢复全部通过验收。

- [ ] PM-T003-I03 实现周期锁定与周期人员快照
  - 前置任务：PM-T003-I02
  - 功能范围：立即锁定、定时锁定、周期级手动/自动名单规则、锁定执行和快照展示。
  - 代码交付物：锁定业务服务、定时执行器、快照写入和状态查询。

  - 完成定义：快照、定时锁定、权限和审计全部通过验收。
