# PM-T009 验收契约（草案）

## Given/When/Then

- Given 任务绑定模板快照；When 打开自我总结任务；Then 页面标题、题目和顺序来自 API/模板，不使用前端固定文案。
- Given 模板包含富文本题；When 页面加载；Then 使用现有富文本组件渲染并支持编辑。
- Given 评级题为必填；When 未选择评级提交；Then 阻止提交并定位评级字段。
- Given 评级题为非必填；When 未选择评级提交；Then 不因该字段阻止提交。
- Given 模板返回评估规则颜色；When 选择评级；Then 选中态使用配置颜色。
- Given 新建或编辑评分评级时先后选择两个评估项；When 确认内容；Then 仅保存和展示最后选择的评估项，不残留旧 item。
- Given 评估题规则等级被修改；When 打开模板配置填写内容；Then 预览只显示该评估题当前等级；When 项目启动并进入填写页；Then 填写页显示同一评估题及同一组冻结等级与颜色。
- Given 评估题保存为下拉样式；When 重新编辑、选择到模板并进入绩效填写；Then 三处均保持下拉样式，不得重置为标签样式。
- Given 评估题保存为标签样式；When 进入模板预览和绩效填写；Then 两处均使用共享评级组件渲染连接标签。
- Given 内容块未开启允许添加多个；When 打开填写页；Then 只显示一组填写项且不显示添加按钮，答案保持单值。
- Given 内容块开启允许添加多个；When 打开填写页；Then 显示统一“添加”按钮；点击后增加整组填写项。
- Given 已增加第二组；When 页面渲染；Then 不显示“第 N 条”和实例间横线，字段名称显示为“名称1、名称2……”；每组均使用公共删除图标。
- Given 存在多组；When 删除任意实例（包括第一条）；Then 该实例内所有字段答案同步删除且至少保留一组；只剩一组时不显示任何删除图标。
- Given 多组内容均已填写；When 提交；Then 同一内容块字段按实例索引提交数组答案，服务端逐实例执行必填校验。
- Given 价值贡献为必填；When 未选标签或补充输入为空；Then 阻止提交并定位该字段。
- Given 用户编辑任意字段；When 内容变化；Then 自动保存，失败时保留输入并提示。
- Given 项目修改了工作总结节点的开始/截止时间；When 用户重新打开任务或调用草稿/提交接口；Then 服务端按项目当前时间判断权限，未开始时不可编辑/提交，已开始时使用新截止时间，历史答案和节点模板不变。
- Given 截止时间内已提交；When 用户再次编辑提交；Then 允许修改和再次提交。
- Given 截止时间后未提交；When 用户提交；Then 允许一次提交。
- Given 截止时间后已提交；When 用户打开任务；Then 页面只读且不可再次提交，概览的完成提示显示“该环节已在 {截止时间} 截止；如有疑问，请联系你的 HRBP。”且不显示编辑按钮。
- Given 提交接口失败；When 页面收到错误；Then 保留当前答案并展示错误原因。
- Given 管理员预览同一节点下存在多名员工任务；When 用户进入某一任务并提交后返回概览；Then 概览继续绑定同一 `task_id`，不得切换到其他员工任务。
- Given 工作总结已提交；When 重新加载绩效评估概览；Then 节点显示“已完成”，白色内容区展示已提交答案，不显示“暂未填写”或“去完成”。
- Given 已提交任务仍在截止期内；When 用户查看已完成内容；Then 页面显示“去修改”并重新打开同一任务；截止后不显示修改入口。

## 证据要求

正式实现后需提供 API、数据库答案记录、权限负向测试、组件测试、构建结果和真实页面验收证据。缺少真实运行时 UI 证据时，视觉验收标记为 `not-run` 或 `blocked`。
