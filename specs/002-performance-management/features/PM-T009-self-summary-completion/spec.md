# PM-T009 自我总结任务填写

## 1. 定位

PM-T008 负责项目启动后生成任务；PM-T009 负责用户进入“自我总结”任务后的填写、保存、提交和状态控制。

本功能不重新建设富文本框、评级选择器或标签题控件。页面通过模板配置加载题目，并复用现有表单组件完成渲染。

## 2. 范围

### 本期实现

- 自我总结任务详情页；
- 页面标题使用 API 返回的模板节点名称；
- 根据模板动态加载文本题、评级题、标签题；
- 联动模板内容块的“允许添加多个”设置，按内容块重复添加整组填写项；
- 富文本内容实时自动保存；
- 评级必填规则和评估规则颜色；
- 价值贡献标签与共用补充输入框；
- 提交校验、错误定位和失败保留输入；
- 截止时间内可修改；
- 截止时间后未提交时保留一次提交机会，提交后只读。

### 本期不实现

- OKR 页签内容；
- 翻译、全屏填写；
- 移动端适配；
- 新建富文本、评级、标签基础组件；
- 评价计算、结果发布和后续评价节点。

## 3. 模板驱动原则

- 题目、顺序、题型、名称、描述、是否必填、选项和规则均来自模板快照/API。
- 页面不得按“自我总结”“工作总结”“价值贡献”等文案写死业务分支。
- 通过 `component_type`/`field_type` 选择已有组件，通过配置适配器传入 props。
- 评级选中态颜色来自模板对应评估题的评估规则。
- 价值贡献使用模板配置的一个共用补充输入框。
- `allowMultiple` 属于内容块 root 规则：开启后重复整个内容块实例，不新增模板题目；关闭时保持原单值答案协议。

## 4. 前置依赖

- PM-T003：项目、模板和流程节点配置；
- PM-T007：标签型填写题配置；
- PM-T008：任务记录、任务入口和任务上下文；
- 现有富文本、评级、标签输入和表单校验组件。

## 5. 状态与权限

| 条件 | 编辑 | 提交 |
|---|---:|---:|
| 当前时间早于项目最新节点开始时间 | 否 | 否 |
| 截止时间内且未提交 | 是 | 是 |
| 截止时间内且已提交 | 是 | 是 |
| 截止时间后且未提交 | 是 | 是，仅一次 |
| 截止时间后且已提交 | 否 | 否 |

项目当前节点起止时间由项目设置提供，任务生成时的时间仅作历史兼容回退；服务端是最终权限判断来源，前端不得仅通过隐藏按钮实现限制。
