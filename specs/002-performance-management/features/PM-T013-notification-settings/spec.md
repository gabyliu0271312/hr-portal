## 1. 背景与目标

实现绩效后台「系统设置 → 通知设置」页面，维护系统通知的推送方式。页面按采集参数复用现有绩效复选框组件，飞书推送保持已开启但不可编辑，邮件通知支持管理员即时开启或关闭。

## 2. 范围

### 本期实现

- 通知方式白卡及采集文案。
- 飞书推送：默认开启、展示为禁用状态。
- 邮件：可编辑复选框，附采集中的说明文案。
- GET/PATCH 配置接口、数据库持久化、权限校验和审计事件。
- 页面加载、加载失败重试、保存失败回滚和成功反馈。
- 新增两组策略单选和三项其他通知开关的真实持久化；摘要编辑仍待采集。

### 非范围

- 邮件服务配置、模板编辑、邮件发送队列和投递记录。
- 飞书消息发送、飞书推送开关编辑能力。
- 通知类型拆分、频率/时间段配置和人员范围配置。
- 像素级截图 diff；采集证据不足，保持 blocked。

## 3. 角色与权限

- 页面沿用绩效后台访问上下文。
- GET/PATCH 均要求 `performance.configuration.manage`。
- 服务端是最终授权边界，前端不以隐藏控件替代权限校验。

## 4. 业务规则

- 单例配置记录固定 `id=1`。
- 首次读取无记录时返回默认值：`feishu_push_enabled=true`、`email_enabled=false`。
- 飞书推送本期只读；PATCH 不接受 `feishu_push_enabled` 字段。
- 邮件及五项策略开关变更即时提交；请求失败恢复变更前状态并提示，刷新/重开读取数据库值。
- 策略默认值来自采集默认态：实时发送、仅终评评分评级变化通知、其他三项全部开启；目前只维护配置，不接通知发送链路。
- PATCH 拒绝未知字段。
- 每次实际配置变更写入审计事件 `PERFORMANCE_NOTIFICATION_SETTING_UPDATED`。

### 5.1 通知设置策略容器（新增采集证据）

来源：`D:\乐逗\Desktop\pm-t013-browser-2026-09-23T07-01-19-124Z.json` 与对应 `-default.html`，URL `https://idreamsky.feishu.cn/perf/admin/system-setting/notify`，viewport `1280×361`，DPR `1.5`，状态包括默认态和 3 个 focus 态。

- 第一组单选：`实时发送`、`校准结束后合并发送`，默认选择 `实时发送`。
- 第二组单选：`仅在终评绩效结果（评分评级）发生变更时通知`、`任意内容发生变更时通知`，默认选择前者。
- 其他通知：`待办任务通知`、`绩效进度日报通知`、`环节启动通知`，默认全部开启。
- 每项展示通知频率、通知时间、节假日和周末屏蔽状态，并提供采集到的“编辑”按钮。
- 用户确认将两组单选和三项复选持久化；同一通知设置 GET/PATCH 扩展五个字段，编辑弹窗与三项摘要字段仍不在本期范围。

策略卡由 GET 返回值驱动，切换后单字段 PATCH，即时更新、失败回滚，刷新读取已保存值；保存中阻止重复操作但不改变其他策略选项的勾选外观或位置。三个编辑按钮仍禁用。

### 5.2 取消勾选确认与单选稳定性

- 任一已开启的其他通知取消勾选前显示确认框，标题“确定取消勾选吗”，正文“取消后，所有人都将收不到该通知。”。
- “保留”或 Esc：关闭弹窗，保持勾选且不调用 PATCH；“确定”：仅对该项 PATCH `false`，成功后关闭并从服务端响应更新；失败保持弹窗与原勾选，允许重试。
- 单选保存期间阻止再次触发，但不原生禁用正在操作的 radio、不中断焦点或改变标签文字颜色；页面不卸载该组。
- 复选保存期间只锁定交互，不将另外两项切成禁用色；未操作项的复选节点、勾选值和可见标记保持不变。保存状态只用不占布局的辅助状态告知，说明行文字固定，避免页面高度变化。
- 每项灰色摘要随该项勾选显示；取消勾选只在确认 PATCH 成功后隐藏该项摘要及“编辑”按钮，保留/保存失败仍显示。重新勾选立即恢复摘要，若保存失败则回滚隐藏；另外两项保持原显示状态。
