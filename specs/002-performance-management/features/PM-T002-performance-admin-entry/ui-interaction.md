# PM-T002 最小交互说明：绩效后台入口与设置壳

本文件记录既有界面的入口调整；独立设置壳的实现以 `../../ui-blueprints/PM-T002-performance-settings-shell.md` 为准。

## 1. 入口与布局

- 页面：既有绩效应用顶栏 PerformanceLayout。
- 触发器：右上角显示头像，无头像时使用姓名首字或默认头像；同时显示姓名和下拉箭头。
- 菜单：点击触发器展开；点击页面空白处、按 Esc 或完成跳转后关闭。
- 顶部 Tab：仅保留工作台、绩效评估、项目管理；移除后台设置。

## 2. 菜单项

| 项目 | 展示条件 | 行为 |
|---|---|---|
| 后台管理 | 同时具备 performance.admin 和至少一项绩效内部配置权限 | 在新 Tab 打开 /performance/settings |
| 退出登录 | 已登录用户 | 复用当前 HR Portal 退出登录流程 |

语言、时区不在本任务显示或实现。

## 3. 权限与状态

- 无后台权限：不显示后台管理；不以禁用态占位。
- 直接访问 /performance/settings：显示既有系统无权限反馈或重定向，不能渲染后台设置内容。
- 加载中：用户菜单权限未就绪时，不展示后台管理，避免短暂越权闪现。
- 设置页：使用独立后台布局，不显示 HR Portal 或绩效前台导航。

## 4. 独立后台设置壳（PM-T002-T02）

- 顶栏：深色品牌栏，左侧显示“创梦绩效设置”，右侧仅保留当前用户头像/菜单。
- 左侧栏：只显示“应用设置”分组，菜单顺序为周期与项目、席位管理、绩效模板、评估题管理、权限管理、系统设置。
- 移除项：不显示通用设置分组和飞书管理后台入口。
- 默认项：席位管理（与已确认参考图一致）；主内容显示对应标题和“功能建设中”占位，不展示配置表单。
- 菜单切换：在设置壳内切换占位标题，不影响前台路由或打开额外窗口。
- 无权限：路由门禁生效时不得渲染设置壳。

## 5. 不变项

- /performance/settings 路径保持不变。
- 不调整工作台、评估、项目管理的页面内容与菜单。
- 不创建后台具体模块、表单或数据接口；T03 仅确认周期与项目的规格和 UI。
