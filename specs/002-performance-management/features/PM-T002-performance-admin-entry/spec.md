# PM-T002 绩效后台入口与设置壳

- 状态：开发中（PM-T002-T01、PM-T002-T02 已完成；PM-T003 周期创建需求已确认，待开发）
- 确认日期：2026-08-04
- 关联路线：阶段 1 基础应用骨架；为后续周期配置后台提供入口
- 前置规格：Spec 002 启动入口、PM-001 角色与授权规格

## 1. 背景与目标

### 背景

绩效应用已具备 /performance/settings 占位页和顶部后台设置 Tab，但后台配置属于管理动作，不应与工作台、绩效评估、项目管理并列。用户确认采用右上角用户菜单中的后台管理作为入口，参考提供的菜单示意图。

### 目标

- 将绩效后台入口迁移到绩效应用右上角用户菜单。
- 保持现有 /performance/settings 路由，避免影响后续配置模块。
- 同时校验 HR Portal 后台入口权限与绩效内部配置权限；菜单隐藏不是访问控制。
- 提供独立于绩效前台的后台设置壳，为后续周期管理提供稳定入口。

### 非目标

- 不实现完整后台业务配置功能或具体配置表单。
- 不实现周期、流程模板、评价模板、等级、强制分布、项目规则、申诉规则、人员同步或权限配置。
- 不实现语言、时区等 HR Portal 全局个人设置。
- 不修改独立绩效超级管理员仅管理绩效管理员账号的权限边界。

## 2. 角色与场景

| 角色 | 入口 | 操作 | 成功结果 | 无权限处理 |
|---|---|---|---|---|
| 有后台入口和内部配置权限的绩效管理员 | 绩效页右上角用户菜单 | 点击后台管理 | 进入 /performance/settings | 不适用 |
| 仅有 performance.app 的普通用户 | 右上角用户菜单 | 打开菜单 | 可继续使用前台功能 | 不展示后台管理；直接访问设置路由时拒绝 |
| 绩效超级管理员 | 独立账号菜单 | 打开菜单 | 仅可使用既有管理员账号能力 | 不展示业务后台管理；直接访问时拒绝 |

## 3. 功能范围

| 功能项 | 本期实现 | 说明 |
|---|---|---|
| 顶部后台 Tab 移除 | 是 | 不再将后台设置作为前台业务 Tab。 |
| 用户下拉菜单 | 是 | 使用头像或姓名触发器，包含后台管理和退出登录。 |
| 后台入口可见性 | 是 | 同时满足 performance.admin 与至少一项绩效内部配置权限。 |
| 路由访问校验 | 是 | 未满足条件时禁止访问 /performance/settings。 |
| 独立后台设置壳 | 是 | 新 Tab 打开；不复用绩效前台顶部与左侧导航。 |
| 设置菜单占位 | 是 | 仅实现应用设置菜单及对应占位内容。 |
| 周期与项目具体功能 | 否 | 在 PM-T003 完成规格与 UI 确认后，再拆分实现任务。 |

## 4. 影响分析

| 层级 | 是否影响 | 具体对象 | 兼容性风险 |
|---|---|---|---|
| 前端路由 | 是 | /performance/settings 守卫 | 保留既有 URL。 |
| 页面布局 | 是 | PerformanceLayout、PerformanceAdminLayout | 后台路由需使用独立布局。 |
| API | 否 | 无新增业务 API | 复用 PM-001 访问上下文。 |
| 数据库 | 否 | 无 | 不涉及迁移。 |
| 权限 | 是 | 入口权限和内部配置权限 | 前后端均须拒绝越权。 |
| 外部系统/UCP | 否 | 无 | 不涉及。 |

## 5. 技术与交互约束

- 展示条件：同时具有 HR Portal 的 performance.admin 和至少一项配置权限；第一期识别 performance.authorization.manage、performance.configuration.manage、performance.cycles.manage、performance.projects.manage。
- 仅靠前端隐藏不构成授权；前端路由守卫必须拒绝无权限访问，后续实际后台 API 继续按各自内部权限校验。
- /performance/settings URL 不变；后台管理从用户菜单以新 Tab 打开。
- 独立绩效管理员账号以 PM-001 访问上下文判断权限；绩效超级管理员没有业务配置权限时不得看到入口。
- 后台壳视觉参考为用户提供的截图：左上角品牌文案使用“创梦绩效设置”；保留应用设置区，移除通用设置和飞书管理后台。

## 9. 验收标准

- 有权限用户可从右上角菜单进入原有 /performance/settings。
- 无权限用户看不到入口，直接访问设置 URL 也不能进入。
- 顶部业务 Tab 不再出现后台设置。
- 后台管理在新 Tab 中打开，且不显示 HR Portal 或绩效前台导航。
- 后台左侧仅显示应用设置菜单，不显示通用设置和飞书管理后台。
- 设置菜单只提供占位内容，不提前实现后台配置业务。
- 前端构建和路由权限回归通过。
