# PM-T010 项目管理（项目管理员工作台）

## 1. 定位

PM-T008 负责项目启动与任务生成；PM-T010 为**项目管理员/HRBP** 提供项目管理入口：左侧复用绩效评估的侧栏框架（顶部周期筛选、折叠分组、子菜单），右侧整块内容区。

本期只交付侧栏框架 + 周期/项目数据绑定 + 「周期概览」入口；右侧各项目的管理内容为后续任务。

## 2. 范围

### 本期实现

- 项目管理页左侧栏：复用绩效评估侧栏的视觉与交互（顶部筛选下拉、分组折叠/展开、子菜单选中态、侧栏收起柄）；
- 顶部筛选为**周期**下拉：仅显示本人涉及（作为项目管理员或 HRBP）的周期；
- 单一分组，名称「项目管理员」；
- 子菜单：「周期概览」固定入口 + 该周期下已启动且本人涉及的项目名称；
- 右侧内容区：本期为周期概览占位（项目清单基础信息），具体管理功能后续任务；
- 后端概览接口：按本人涉及过滤周期与项目，HRBP 维度接口预留、逻辑后补。

### 本期不实现

- HRBP 身份的实际匹配逻辑（接口已预留字段，待 HRBP 设置功能就绪后补齐）；
- 数据权限角色体系（后续迭代）；
- 项目编辑、成员管理、进度等管理内容页；
- 移动端适配。

## 3. 可见性规则（本期实际行为）

| 层级 | 规则 |
| --- | --- |
| 周期下拉 | 周期内存在至少一个已启动项目且本人在其 `administrators` 中 → 周期出现（HRBP 匹配预留，当前恒为假） |
| 项目子菜单 | `status=STARTED` 且本人在 `administrators` 中 → 项目出现（HRBP 匹配预留） |
| 空态 | 无任何涉及周期时，侧栏显示空态，右侧显示无权限/无数据提示 |

管理员视角（`_is_admin_preview`）与绩效评估概览保持一致：周期管理员可预览全部，不受本人涉及限制。

## 4. 身份匹配现状与假设

- 项目管理员存于 `PerformanceProject.administrators`（JSONB 字符串数组，当前按**姓名**存储）；
- 本人匹配：通过可信 actor 解析出 `display_name`，与 `administrators` 数组做字符串包含匹配；重名/改名风险已记录，本期按现状匹配；
- HRBP：现有模型无「项目 → HRBP」关系；本期接口返回结构预留 `hrbp_scope` 字段且恒为空，待 HRBP 设置就绪后在同一接口内补齐，不改前端契约。
