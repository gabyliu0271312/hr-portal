- [x] 优先级为先A报表可靠性、再B主数据；主数据全部范围保留，A不依赖X2105/X2174/X2176。
- [x] 人员范围允许有权员工所有中心明细；成本中心仅汇总，跨组织人员贡献须计入而不公开其明细。
- [x] 同一批准事实D用于明细、S=D OR批准中心范围用于汇总；双路径去重，不两份SUM相加，不扩展为任意标签/事实OR。
- [x] 分析分组与授权条件分离；中心×组织×期间合法汇总、组织业务筛选不自动加组织授权AND。

- [x] 员工分组/筛选/名单/匿名逐行/下钻重新人员裁决；内部JOIN键/批准COUNT DISTINCT不机械判明细。

- [x] 每个实际事实受控，参考最小投影、各类JOIN保留侧/NULL/多事实/一对多/笛卡尔积和汇总计数有实施/测试要求。
- [x] 标准目录是唯一语义源，物理/输出/展示consumer职责分开；已删除global_fields、既有动态CRUD及ODS清洗事实不被漏记成从零建设。

- [x] 属性固有语义、绑定/关系/报表用法/未来能力分层；目录owner/审核/替补/批量/积压及真实使用验收明确。
