月度成本入账表—只读拉取 API

一、接口概览

接口名称：月度成本入账表
调用方式：对方系统主动拉取
请求方法：GET
接口地址：https://hr-portal.example.com/api/v1/push-targets/17/data
数据范围：2026 年 6 月；费用类型仅包含“工资”“劳务”
返回内容：按“发薪月 × 客户 × 费用类型 × 成本中心”聚合后的成本入账数据
返回格式：JSON 数组
分页：当前接口不分页，一次返回全部符合条件的数据
写入能力：无，仅支持读取
鉴权方式：X-App-Id + X-App-Secret 请求头

说明：
- https://hr-portal.example.com 是文档示例域名。IT 接入时请替换为 HR Portal 实际生产域名。
- 推送配置 ID 已确认是 17。
- 接口实际响应只返回字段编码，不会同时附带中文字段名。本文同时提供字段中文名称对照表，便于业务理解和字段映射。

二、鉴权请求头

Header：X-App-Id
是否必传：是
说明：接口调用标识
当前值：dxz4FYbOQLNIZfjim9mI

Header：X-App-Secret
是否必传：是
说明：接口调用密钥
取值：由 HR Portal 管理员通过受控渠道单独提供

Header：Accept
是否必传：建议
取值：application/json

注意：AppSecret 不要写入本文档、邮件正文、群聊或代码仓库。

三、cURL 调用示例

curl --request GET "https://hr-portal.example.com/api/v1/push-targets/17/data" \
  --header "X-App-Id: dxz4FYbOQLNIZfjim9mI" \
  --header "X-App-Secret: 由HRPortal管理员单独提供的AppSecret" \
  --header "Accept: application/json"

如需只查看第一条数据，可在 Linux、macOS 或 Git Bash 环境执行：

curl --silent --show-error --request GET "https://hr-portal.example.com/api/v1/push-targets/17/data" \
  --header "X-App-Id: dxz4FYbOQLNIZfjim9mI" \
  --header "X-App-Secret: 由HRPortal管理员单独提供的AppSecret" \
  --header "Accept: application/json" \
  | jq '.[0]'

四、Python 调用示例

import requests

url = "https://hr-portal.example.com/api/v1/push-targets/17/data"

headers = {
    "X-App-Id": "dxz4FYbOQLNIZfjim9mI",
    "X-App-Secret": "由HRPortal管理员单独提供的AppSecret",
    "Accept": "application/json",
}

response = requests.get(
    url,
    headers=headers,
    timeout=30,
)

response.raise_for_status()
rows = response.json()

print(f"拉取成功，共 {len(rows)} 条汇总记录")

for row in rows:
    print(
        f"发薪月：{row.get('dwd_emp_monthly_salary.pay_month')}，"
        f"客户：{row.get('dwd_emp_monthly_salary.client')}，"
        f"费用类型：{row.get('dwd_emp_monthly_salary.expense_type')}，"
        f"应发工资：{row.get('calc.gross_salary_including_bonus')}"
    )

八、返回状态说明

HTTP 状态码：200
说明：请求成功
建议处理方式：解析 JSON 数组

HTTP 状态码：200，响应 []
说明：请求成功，但当前无符合条件数据
建议处理方式：视为正常空数据结果

HTTP 状态码：401
说明：X-App-Id 或 X-App-Secret 缺失或错误
建议处理方式：核对凭证内容、大小写及请求头名称

HTTP 状态码：403
说明：调用方 IP 不在白名单
建议处理方式：联系 HR Portal 管理员配置出口 IP

HTTP 状态码：404
说明：推送配置不存在，或不是 API 暴露类型
建议处理方式：核对接口地址中的 17

HTTP 状态码：500
说明：服务端读取或报表执行异常
建议处理方式：提供请求时间、响应内容给 HR Portal 管理员排查

九、接入与安全约定

1. 必须通过 HTTPS 调用。
2. AppSecret 仅保存于对方系统的密钥管理工具或受控配置中心。
3. 禁止将 AppSecret 写入前端代码、客户端代码、日志、截图、邮件或群聊。
4. 当前 IP 白名单为空；正式联调前，对方应提供固定的出口公网 IP，由 HR Portal 管理员加入白名单。
5. 该接口返回薪资、社保、个税、扣款等敏感财务信息；调用方应遵循最小权限、访问日志审计和数据留存管理要求。
6. 报表当前固定读取 2026 年 6 月、工资和劳务两类数据；若要切换月份或费用范围，需要由 HR Portal 管理员调整报表配置。
