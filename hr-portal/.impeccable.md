## Design Context

### Users
HR Portal 面向多角色混合用户，包括 HRBP、薪酬绩效、HR 组织管理员、系统管理员、IT/接口维护人员以及部分业务协作角色。用户主要在企业内网环境中完成权限管理、数据源配置、报表中台、接口推送、流程与数据校验等工作，关注准确性、可追溯性和低出错率。组织功能的首要使用者是 HR 组织管理员，核心任务是快速检索、展开并核对组织层级与启停状态。

### Brand Personality
整体气质应专业、稳健、可信。界面需要让业务用户有信心操作敏感数据和系统配置，也要让 IT/管理员能快速定位配置项、连接信息和执行状态。

### Aesthetic Direction
沿用现有 Vue 3 + Element Plus 企业后台风格、浅色主题、蓝色主色和既有设计 token。绩效系统已经形成的设计 token 与通用交互组件作为全局视觉和组件基线，主数据、组织等模块直接复用，只做业务语义适配，不复制局部视觉体系。避免强烈装饰、炫技动效或与当前系统割裂的视觉语言；局部交互可以更清晰、更顺手，但不改变整体产品气质。

### Design Principles
1. 配置类界面优先清晰、可确认、低误操作，关键操作必须有明确反馈。
2. 绩效系统现有设计 token 和成熟组件是全局基线；跨模块组件提升到共享目录共同消费，不在业务模块复制实现。
3. 对敏感信息采取渐进披露，默认隐藏，显式操作后展示或重置。
4. 文案短而准确，面向业务用户解释结果，面向管理员保留必要技术细节。
5. 小范围增强优先，不为单个控件引入重型视觉或复杂交互。
