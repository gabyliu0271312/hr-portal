# 字段本地维护模式（FLM0001）

## 目标

让已由外部系统同步发现的业务字段可被一次性切换为手工字段。切换后，数据视图允许编辑该字段，后续同步不再以源端同名字段写入。

## UI 与交互

- 入口仅位于“数据仓库 → 数据资产 → 字段管理”；“系统设置 → 字段管理”继续是只读兼容入口。
- 字段列表显示“系统同步”或“手工字段”状态。
- 对系统同步字段提供“改为手工字段”操作；弹窗明确说明该操作不可恢复、数据视图可编辑、后续同步不覆盖人工值。
- 业务主键字段与计算字段不可切换，并展示不可操作原因。

## API 契约

- `PATCH /api/v1/table-columns/{table}/{column_id}/local-maintenance`
- 权限：`warehouse.assets/U`。
- 请求：`{ "confirm": true }`。
- 成功后将 `table_columns.auto_discovered` 置为 `false`，返回完整字段元数据。
- 字段不存在返回 `404`；未确认、业务主键或计算字段返回 `400`。
- 操作幂等：已是本地维护字段再次调用不改变数据并返回当前字段。

## 同步契约与验收

- 同步层以 `auto_discovered=false` 识别本地维护字段；源端同名值对新旧记录均必须丢弃，既有行保留存量人工值。
- 前端字段定义接口必须返回 `auto_discovered`，使通用控件能展示正确状态。
- 覆盖：成功切换、主键拒绝、计算字段拒绝、未确认拒绝，以及切换后同步保留人工值的定向测试。
